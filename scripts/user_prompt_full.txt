IMPORTANT INTERPRETATION
==================================================

DO NOT claim:

"Fusion always performs better."

That is not supported.

Correct interpretation:

- Network Random Forest achieved the highest F1 among the tested configurations: 0.9643.
- Fusion Random Forest achieved F1 = 0.9286.
- However, fusion Random Forest had lower FPR:
  Fusion = 0.0213
  Network = 0.0312
- Fusion therefore shows a useful detection-quality / false-positive trade-off under the tested conditions.
- Workload-only detection was substantially weaker.
- The experiment demonstrates that telemetry choice materially affects detection behavior.

The research contribution must NOT be described as simply:
"we combine network and workload telemetry."

The previous literature review already identified Morsli et al. (2025), which demonstrated network + container feature fusion.

Instead frame the contribution around:
- controlled telemetry ablation
- session-isolated evaluation
- telemetry-choice analysis
- false-positive trade-offs
- evidence-aware inference
- reproducible Kubernetes experimental pipeline
